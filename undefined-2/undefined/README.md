# 전자형 점자 자료



### 요약 (차이는이것 밖에 없음)

* **분권**: 하지 않는 것을 원칙으로 한다. (단, 원본 별책은 분권 가능)
* **자료 끝**: 짝수 페이지로 맞추지 않는다.
* **원본 발행 정보**: 분권 정보(없으면 서명) 아래 빈줄 없이 적는다.
* **점자 발행 정보**: 원본 발행 정보 아래 한 줄을 띄어 적는다.
* **차례 페이지 표기**: `⠠⠄원본 페이지 번호만 기입함.⠠⠄`
  * 단, (일부 혹은 전체) 원본 페이지가 없으면 점자 페이지만 표기하는 것도 가능
