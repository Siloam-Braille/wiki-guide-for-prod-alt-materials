# 제7조(페이지 정보)

① 페이지 정보는 해당 페이지의 시작 위치에 입력한다.

\
② 페이지 정보는 새로운 줄에 따로 입력하고, 이어지는 문장은 <kbd>Enter</kbd>키를 눌러 다음 줄에 입력한다.

\
③ 본문은 아라비아 숫자 1페이지부터 시작하되, 선행페이지가 로마숫자일 경우에는 로마숫자부터 시작하고, 로마숫자는 자판의 영어로 조합한다.

* 연속간행물의 논문과 같이 원본자료의 일부분을 제작하거나 분권하는 경우 원본자료와 동일한 페이지로 시작한다.
* 원본에 `001`, `002`로 표기된 경우에는 쪽 정보 `1`, `2`로 제작한다.

\
④ 원본에는 빈 페이지가 아니지만 데이지편집상 내용이 빈 페이지가 될 경우에는 페이지 번호를 입력하고 해당 페이지의 내용을 간략하게 설명한다.



⑤ 내용이 없는 페이지이더라도 페이지 번호를 매긴 후 ‘빈 면’이라고 적는다.



⑥ 본문 외의 부분에 페이지 번호가 없을 경우 본문의 일련번호와 연결되도록 페이지를 매기되 선행 페이지 번호가 본문의 시작 페이지를 넘어서는 만큼 ‘0’에 붙임표를 붙이고 아라비아 숫자를 순차적으로 입력한다.



⑦ 페이지 번호를 입력하는 위치가 단어 사이에 올 경우에는 원본자료대로 입력한다.
