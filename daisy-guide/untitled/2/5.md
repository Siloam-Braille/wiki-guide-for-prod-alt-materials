# 제5조(서지 및 제작 정보)

① 서지사항에서 서명, 저자, 발행처 등의 기본 정보는 메타정보로 입력하고 제작 정보는 표지 마지막 부분에 입력한다.





<details>

<summary>서지사항 작성 방법</summary>

* 서명은 국립중앙도서관에서 도서 검색 후 참고(\[예 1] 참조)
* 편/권차와 권/편제는 상세화면 참고(\[예 2] 참조)
* 저자는 국립중앙도서관에서 도서 검색 후 참고(\[예 1] 참조)
* 발행처는 국립중앙도서관에서 도서 검색 후 참고(\[예 1] 참조)

</details>

② 표지, 책날개, 지은이 소개, 판권지 등의 도서 정보는 원본자료의 순서대로 입력한다.

1. 표지의 경우
2. 앞부분 책날개의 경우
3. 판권지의 경우
4. 뒷부분 책날개의 경우
5. 뒤표지의 경우



➂ 표지와 뒤표지는 반드시 목차를 생성하며, 표지 내용이 없는 경우 속표지 내용을 입력하고 뒤표지 내용이 없는 경우 “빈 면”이라 입력한다.



④ 띠지는 입력하지 않는다.
