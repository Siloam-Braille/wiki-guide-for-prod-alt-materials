# 제10조(분권)

① 데이지자료의 용량이 커서 보조공학기기에서 재생되지 않는 경우에는 분권한다.



② 각 권의 분량은 서로 비슷하게 하되, 1단계 목차생성을 기준으로 분권한다.



③ 분권된 도서에는 각각 표지와 제작 정보 및 판권지를 입력한다.

{% hint style="info" %}
※ 판권지는 원본과 동일한 위치에 분권된 도서별로 각각 입력한다.
{% endhint %}



④ 분권된 각 권의 도서파일명에는 분권이 포함하는 페이지 범위를 적는다.

{% code title="[예]" %}
```
한글경악전서(1~498쪽)
한글경악전서(499~935쪽)
한글경악전서(936~1403쪽)
```
{% endcode %}
