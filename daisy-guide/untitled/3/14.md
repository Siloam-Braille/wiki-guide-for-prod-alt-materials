# 제14조(시각자료 편집)

① 시각자료의 그림 파일 형태는 tiff 파일은 제외하고, jpeg, jpg, png 등의 파일로 삽입한다.



② 이미지 크기는 제작 및 검수 시 확인이 용이해야 하고, 이미지 질은 내용 확인이 될 수 있도록 선명하여야 한다.



③ 시각자료가 문장 중간에 나올 경우 원본자료와는 달리 문단과 문단 사이에 시각자료를 삽입한다.

⑤ 시각자료가 한 페이지를 초과하는 경우 각각 페이지 번호를 매기고 다음 각 호를 따른다.

1. 표가 한 페이지를 초과하는 경우에는 원본과 동일하게 표 내용을 표시하되, 가독성을 저해하는 경우 제작자 주를 사용하여 표의 내용을 임의로 옮긴다.
2. 표를 풀지 않고 원본과 동일하게 작성한 경우에는 다음 페이지에 열 제목과 행 제목이 생략되어 있어도 반복하여 표시한다.

{% hint style="info" %}
※ 다음 페이지에 표 제목은 다시 표시하지 않는다.
{% endhint %}
