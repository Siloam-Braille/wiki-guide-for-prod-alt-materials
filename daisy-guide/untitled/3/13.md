# 제13조(제작자 주)

① 원본자료를 제작하는 과정에 특기할 사항이 있을 경우에는 ‘`제작자 주`’를 넣고 특기 사항을 설명한다.



② 제작자 주는 별표(`*`)를 입력하고 한 칸 띄운 후 “`제작자 주:`”와 내용을 개조식으로 표현하고 마침표를 찍는다.

{% code title="[예]" overflow="wrap" lineNumbers="true" %}
```
*␣제작자 주: ~함. ~로 됨. ~임.
```
{% endcode %}



③ 제작자 주의 내용이 도서에 반복적으로 나올 경우에는 차례 맨 마지막 부분에 “`이 책의 제작자 주:`”로 한 번만 명시하고, 특정한 내용일 경우에는 해당 내용이 나오기 전에 각각 “`제작자 주:`”로 명시한다.
