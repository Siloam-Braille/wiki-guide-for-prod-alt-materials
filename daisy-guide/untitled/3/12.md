# 제12조(목차제목의 부제목)

① 목차 제목과 부제목 사이에 연결기호가 있는 경우에는 원본 그대로 적고, 연결기호가 없는 경우에는 목차제목 다음에 빈칸 없이 쌍점(`:`)을 입력한 후 한 칸 띄고 부제목을 적는다.



② 목차제목이 쌍점을 포함하고 있을 경우에는 제목 다음에 붙임표(`-`)를 입력하고 빈칸 없이 부제목을 적는다.

{% hint style="info" %}
※ 붙임표와 줄표의 구분이 어려운 경우에는 \
원본도서에 하나만 존재할 경우에는 붙임표를 입력하고, \
두 개로 짝을 이룰 경우에는 줄표를 사용한다.
{% endhint %}
