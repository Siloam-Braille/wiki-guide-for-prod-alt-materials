# 4. 차례 이외의 선행 페이지

차례 이외의 선행 페이지 항목은 다음과 같이 적는다.



1. 전체 점역자 주
   1. 전체 점역자 주는 점자 자료 전체에 적용되는 범례, 미정의 특수 기호 설명 및 기타 점역자의 안내 사항 고지가 필요할 경우 점자 표지 다음 장바꿈하여 적는다.
   2. 모든 항목이 점역자 주에 해당하기 때문에 점역자 주표 `⠠⠄ ⠠⠄`은 생략한다.
   3. 전체 점역자 주의 제목은 ‘`이 책의 점역자 주`’, ‘`점자 일러두기`’ 등으로 적으며, 제목은 가운데 정렬하여 적고 제목과 내용 사이에는 한 줄을 띈다.
   4. 도서 내에서 같은 내용의 점역자 주가 반복하여 적용되는 경우 이를 전체 점역자 주로 처리한다.



2. 원본 자료 겉표지에 책날개가 있을 경우 점자 표지 다음에 장바꿈하여 적고, 꼬리말은 ‘`책날개`’로 적는다.\
   다만, 전체 점역자 주가 점자 표지 다음에 있을 경우 전체 점역자 주 다음 쪽바꿈하여 적는다.



3. 책날개 대신 앞표지 안쪽면에 내용이 있는 경우에는 책날개 점역과 같이 점자 표지 다음에 장바꿈하여 적고, 꼬리말은 ‘`앞표지 안쪽면`’으로 표기한다.



4. 판권 정보의 각 항목(저자, 발행인, 편집인, ISBN, 출판사 정보 등)과 내용을 원본대로 적고, 꼬리말은 ‘`판권 정보`’로 적는다. 이때 항목과 내용 사이를 빈칸으로 구분할 경우에는 두 칸을 띄고, 세로선을 표기할 경우에는 `⠸⠳`으로 적고 세로선의 앞뒤를 한 칸씩 띈다.



5. 머리말
   1. 머리말에 해당하는 제목(머리말, preface, foreword, Introduction 등)은 원본 페이지 번호 다음 줄에 가운데 정렬하여 적고, 제목과 내용 사이는 한 줄 띈다.\
      다만, 머리말에 원본 페이지 번호가 없을 경우 페이지 첫째 줄에 가운데 정렬하여 적는다.
   2. 2판 이상 재출판된 도서의 경우 각 판의 머리말은 각각의 선행 페이지 항목으로 간주하여 쪽바꿈한다.



6. 구성과 특징, 추천사 및 감사의 글 등은 원본 페이지 번호 다음 줄에 가운데 정렬하여 적고, 제목과 내용 사이는 한 줄 띈다.\
   다만, 위의 항목에 원본 페이지 번호가 없을 경우 페이지 첫째 줄에 가운데 정렬하여 적는다.
