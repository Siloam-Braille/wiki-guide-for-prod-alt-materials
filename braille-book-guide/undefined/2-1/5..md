# 5. 후행 페이지

1. 후행 페이지에 해당하는 항목을 적을 때에는 원본 자료의 순서에 따라 적는 것을 원칙으로 한다.   \
   다만, 점자 자료의 후행 페이지 항목의 순서가 원본 자료와 달라지거나 항목을 생략할 경우 전체 점역자 주([2장 1절 4. 1)](4..md#id-1) 참조)를 두어 달라진 내용을 설명한다.



2. 후행 페이지의 시작은 본문이 끝난 다음 장바꿈하여 적고 후행 페이지의 각 항목은 쪽바꿈하여 적는다.



3. 후행 페이지의 제목은 원본 페이지 번호 다음 줄에 가운데 정렬하여 적고 제목과 내용 사이는 한 줄 띈다.   \
   다만, 원본 페이지 번호가 없을 경우 페이지 첫째 줄에 가운데 정렬하여 적는다.



4. 후행 페이지의 꼬리말은 해당하는 제목을 적는다.



5. 색인(찾아보기)
   1. 색인 또는 찾아보기는 일반적으로 생략하나, 학습서 등의 어휘집과 용어 해설 등은 독자의 학습을 돕기 위해 도서에 포함시켜 제작한다.
   2. 색인의 제목은 가운데 정렬하고 내용이 두 단계 이상으로 구성된 경우에는 단계별 제목 표기에 따라 제작한다.
   3. 나열된 단어에 쓰인 특별한 글자체는 반영하지 않는다.
   4. 표제어와 뜻풀이 사이에는 두 칸을 띄어 구분하고, 안내선이 있을 경우 이를 생략한다.
   5. 색인을 생략할 경우에는 ‘전체 점역자 주’에 색인 생략을 고지한다.



6. 뒤표지 안쪽면에 내용이 있는 경우에는 책날개 표기와 같이 본문 다음에서는 장바꿈을, 후행 페이지 마지막 항목 다음에서는 쪽바꿈하여 적고, 꼬리말은 ‘`뒤표지 안쪽면`’ 으로 표기한다. 이때, 바로 앞쪽의 원본 페이지 번호가 페이지행에 이어 표기되지 않도록 주의한다.
